# Security policy

wpx runs part of its work with administrator / root rights (the tunnel engine, firewall rules, scheduled tasks), so
security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use **[Report a vulnerability](https://github.com/qjcky/wpx/security/advisories/new)**
(GitHub private vulnerability reporting). Write in English or Russian. Include the wpx version, the OS, steps to
reproduce and what an attacker gains. Never include your real connection links, keys or passwords.

You will get an answer within a week. Fixes go into the next release; the advisory is published after the update is out.

## Supported versions

Only the latest release gets security fixes. wpx updates itself (Settings → Updates).

## Scope

How wpx protects the PC and its data, and what it does not protect against, is described in
[docs/security.md](docs/security.md).
